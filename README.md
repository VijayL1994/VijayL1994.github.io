# Vijay · Photography

极简黑色主题 · 电影感摄影作品集单页。原生 HTML / CSS / JS，无框架、无构建、无第三方依赖。

```
site-v2/
├── index.html                 页面结构（已内联图片清单，自包含）
├── style.css                  全部样式
├── script.js                  全部交互
├── images/
│   ├── _manifest.json         图片清单（工具数据源）
│   └── *.jpg                  113 张作品图
├── tools/build-manifest.mjs   一键重建清单
└── _serve.js                  本地预览小服务器
```

## 本地预览

页面已**自包含**（图片清单内联在 `index.html` 里），**直接双击 `index.html` 即可在浏览器打开**，无需服务器。`file://` 也能完整显示。

如需开本地服务器：

```bash
node _serve.js        # http://localhost:5173
```

## 换图片

画廊完全由 `images/_manifest.json` 驱动，不用改任何代码。

**方式一 · 批量换（推荐）**

```bash
# 1. 把新照片丢进 images/
# 2. 跑一次：
node tools/build-manifest.mjs
```

脚本会自动读文件头解析宽高、按文件名生成标题，并**保留你手工改过的标题**。

**方式二 · 手动编辑** `images/_manifest.json`：

```json
[
 { "file": "001-xvessel.jpg", "title": "xVESSEL", "w": 1600, "h": 1067 }
]
```

- `file` 相对 `images/` 的文件名
- `title` 悬停时显示的作品名
- `w` / `h` 原始像素尺寸 —— **必填**，用来在图片加载前就算好瀑布流高度，做到零布局抖动

数组顺序就是展示顺序。

**首页大图**在 `script.js` 顶部指定，这张会自动从画廊里排除，不会重复出现：

```js
const HERO_FILE  = '001-photography.jpg';
```

> 关于页为纯文字排版，不放任何配图。

## 分辑（按拍摄类型）

画廊分成 4 个辑，顺序与命名如下（要改顺序或新增辑，直接改 `script.js` 顶部的 `ALBUMS` 数组）：

| # | 英文 | 中文 | 张数 |
|---|---|---|---|
| 01 | Portrait      | 商业人像      | 21 |
| 02 | Product       | 产品拍摄      | 43 |
| 03 | Architecture  | 建筑空间      | 10 |
| 04 | Stage & Event | 演出现场      | 38 |

每张图被显式分配到一个辑（不是按品牌自动归类的），所以同一品牌的不同图可以进不同辑。
要挪图，只需把 `script.js` 里对应辑的 `files` 数组里加减文件名即可。**每个文件名只能出现在一个辑里**——重复出现会被忽略（按首次出现计）。

## 设计说明

**配色** 纯黑 `#0a0a0a` 打底，四级灰阶文字。全站不用任何彩色 —— 颜色只能来自照片本身。

**字体** 标题走系统自带的高对比度衬线（macOS 上是 Didot，Windows 回退 Georgia），正文用无衬线。不加载网络字体，国内访问零延迟、零闪烁。

**动效** 四种，都克制：

| 动效 | 实现 |
|---|---|
| 滚动淡入 | IntersectionObserver 触发，1s 缓出，只跑一次 |
| 视差缩放 | 元素靠近视口中心时轻微放大（最多 3.5%） |
| 悬停放大 | 图片 1.2s 缓出放大到 1.045 |
| 灯箱 | 点击弹出，支持 ← → 翻页、Esc 关闭、移动端左右滑动 / 下滑关闭 |

三层结构让动画互不打架 —— 淡入在 `figure` 上，视差在 `.m-media` 上，悬停在 `img` 上。

## 性能

- 前 6 张 `eager` + `fetchpriority=high`，其余 107 张原生 `loading="lazy"`
- 清单里带原始宽高 → 图片没加载完也能算准瀑布流，CLS 为 0
- 视差用 rAF 节流，且只计算视口内的元素；窄屏（< 720px）直接关掉
- 图片总计 8.6 MB / 113 张，长边压到 1600px、渐进式 JPEG

## 兼容与可访问性

- 瀑布流用 JS 最短列分配，不是 CSS `column-count` —— 各列高度差 0.7%~5%，且相邻作品不会被拆到不同列
- 断点：≥1700px 四列 / ≥1100px 三列 / 其余两列
- 移动端用 `100svh`，不受地址栏收起影响
- 图片可 Tab 聚焦、回车打开灯箱，灯箱有焦点管理
- 尊重 `prefers-reduced-motion`：开启后所有动效自动关闭
- 触屏设备（`hover:none`）自动常显图注、关掉悬停放大
